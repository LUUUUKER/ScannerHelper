========================================================================
  扫码助手 Scanner Helper  1.0.5
  仓库工位试点安装说明
========================================================================

这个包里只有这些东西：

  ScannerHelper.exe    程序本体（单文件，138 MB）
  使用说明.txt         你正在看的这一份
  模式切换与配置条码.pdf  直接打印这个就行（内容和程序里那个按钮生成的一样）
  工具\               现场排查用的检查脚本（平时用不到，见第六节）

没有安装程序，没有要下载的东西，不需要管理员权限。


------------------------------------------------------------------------
一、装之前必须先做的一步（漏了会出大问题）
------------------------------------------------------------------------

  ★ 扫码枪必须先切换到「USB 虚拟串口」模式。

    做法：用扫码枪扫一次厂商说明书里的「USB 虚拟串口 / USB COM / CDC」
          配置条码。每一把新枪都要扫一次。

  为什么这一步不能漏：

    这个程序是从串口读条码的。如果枪还停在默认的「USB 键盘」模式，
    程序的串口一个字节也收不到，但它**不会报错**——串口好好地开着，
    只是没数据。

    而与此同时，扫码枪会直接往业务软件里打字，原始条码原封不动地进去了。

    也就是说：工位看起来一切正常，程序界面上模式也显示得好好的，
    而它本来要防的事正在发生。

  程序对这种情况有一道保险：串口开着但超过 10 分钟收不到任何数据，
  主界面上会出现告警文字。但那是事后补救，不能代替先扫这一次配置条码。

  ★ 建议把那张配置条码打印出来贴在工位上。


------------------------------------------------------------------------
二、安装
------------------------------------------------------------------------

  1. 在目标电脑上建一个固定的文件夹，例如：

         C:\ScannerHelper\

     不要直接从 U 盘运行。U 盘一拔程序就没了，而且「开机自动启动」
     也会指向一个不存在的路径。

  2. 把 ScannerHelper.exe 复制进去。

  3. 双击运行。第一次启动会慢几秒（程序在解开自带的运行时），之后就快了。

  4. 点「设置」，在「扫码枪」一栏里选中枪所在的串口（通常是 COM3、COM4
     这样的名字），点「保存」。

     如果下拉框里一个端口都没有：枪没插好，或者第一步的配置条码没扫。

  5. 如果这台电脑要长期用，在设置里勾上「开机自动启动」。


------------------------------------------------------------------------
三、日常使用
------------------------------------------------------------------------

  两种模式：

    SN 模式     扫到什么发什么，原样输出。程序每次启动都是 SN 模式。
    SKU 模式    按设置里的规则从条码里截出 SKU 再发出。

  切换模式有两种办法：

  【办法一】扫一下墙上的条码 —— 推荐

    包里的「模式切换与配置条码.pdf」直接打印就行。
    （也可以在设置里点「打印模式切换条码」，打开的网页内容完全一样。）

    这张网页有两页：
      第一页 工位卡 —— 切换 SN / SKU 的两枚码，剪开贴在工位上
      第二页 装机卡 —— 扫码枪自己的配置码（恢复出厂、2.4G、配对、虚拟串口）

    ★ 第二页不要贴在工位上，跟装机工具放在一起。上面的「恢复出厂设置」会把枪
      打回键盘模式，那时本程序收不到任何数据、也不会报错，而条码会原封不动地
      进业务软件。工位上贴着它，早晚有人扫错一张。

    ★ 第二页只适用于 Tera D5100。换型号要按那把枪的说明书重做。之后扫「切到 SKU 模式」那张纸就切过去，扫另一张切回来。

    这两枚条码不会被发送到业务软件里。工人手里本来就拿着扫码枪，
    扫一下比腾出一只手去找按键快，而且不存在「这台电脑上这个键被占了」。

    ★ 印出来之后请先扫一次试试。打印机墨点扩散可能把细条糊在一起，
      纸上看着好好的却扫不出来。

  【办法二】按键

    Insert      在 SN / SKU 之间切换（默认值，可以改）
    F10         有一枪没发出去时，强制把原始码发出去
    Esc         有一枪没发出去时，丢弃这一枪

    F10 和 Esc 只在「有一枪卡住等你决定」的时候才被本程序占用，
    其余时间这两个键在别的程序里照常使用。

    ★ 切换键在设置里可以改。旁边会当场显示「这台电脑上可用」还是
      「被别的程序占用了」——选完就知道成没成，不用装完才发现按了没反应。

    ★ 从 1.0.1 及更早版本升级上来的电脑，切换键仍然是原来的 F8。
      要用新的默认值，在设置里把它改成 Insert 即可（程序不会替你改掉
      一个已经配置好的键，否则界面显示的和实际生效的就不是一回事了）。

  暂停：

    界面上的「暂停」按钮。暂停期间程序不做任何解析和校验，扫到的码
    原样发出，三个快捷键也全部让出去。这是出问题时的安全阀，
    鼠标点一下就能进出，展开窗口和小窗都有这个按钮。

  窗口：

    最小化 = 缩成小窗（小窗始终浮在最上面，绝不会缩到看不见）
    小窗上的「展开」回到大窗口
    右上角的 × 是真的退出，会先问一次


------------------------------------------------------------------------
四、程序把东西写在哪儿
------------------------------------------------------------------------

  设置：  %APPDATA%\ScannerHelper\settings.json
  日志：  %APPDATA%\ScannerHelper\logs\scanner-年-月-日.log

  （把 %APPDATA% 直接粘进文件资源管理器的地址栏就能到。）

  日志一天一个文件，默认保留 14 天，自动删旧的。设置里有「打开日志文件夹」
  按钮可以直接跳过去。

  ★ 程序运行期间不要手工改 settings.json。程序退出时会把它内存里的那份
    写回去，你改的内容会被覆盖掉。要改就在设置界面里改。

  ★ 如果条码内容不方便出现在日志里，在设置里勾上「日志里遮住条码内容」。
    勾上之后日志里记的是 AB************89 这样的形式——保留长度和两头，
    足够对上是哪一枪，又不至于把整个码写进去。


------------------------------------------------------------------------
五、卸载
------------------------------------------------------------------------

  1. 先在设置里去掉「开机自动启动」的勾（否则注册表里会留一条指向
     不存在文件的启动项）。
  2. 退出程序。
  3. 删掉 C:\ScannerHelper\ 文件夹。
  4. 如果连设置和日志也不想留，删掉 %APPDATA%\ScannerHelper\ 文件夹。

  程序不写任何其他位置，没有服务，没有驱动。


------------------------------------------------------------------------
六、出问题时先看这里
------------------------------------------------------------------------

  「扫码没反应，业务软件里什么都不出现」

     先看程序主界面：
       - 显示「扫码枪已连接」但很久没有「最近一枪」，而条码却直接进了
         业务软件 → 枪掉回键盘模式了，重扫第一步的配置条码。
       - 显示断开 → 枪没插好，或端口号变了（换了 USB 口会变）。
         点设置里的「重新列出」重新选一次。

  「打不开端口 / 端口被占用」

     串口是独占的。别的程序先占住了——常见的是串口调试助手、
     厂商配置工具，或者本程序自己开了第二个实例。关掉那个再试。

  「杀毒软件把它拦下来了」

     这个程序会用 SendInput 往别的程序里打字，行为上和一部分恶意软件
     相似，可能被误报。请仓库 IT 按哈希加白名单：

       文件：  ScannerHelper.exe
       版本：  1.0.5
       SHA256: C62EAF3B6DB85BC41DB70374A7E5295A97465CCAFA0D852349CC12005320420A

     （在 PowerShell 里用
        Get-FileHash .\ScannerHelper.exe -Algorithm SHA256
      可以自行核对。）

  「扫了码，但业务软件里什么都没出现，日志里却写着已发出」

     检查是不是用管理员权限运行了本程序。业务软件是普通权限运行的，
     本程序权限更高的话，发出去的按键会被 Windows 挡在门外，
     表现正是「日志一切正常，业务软件里什么都没有」。

     ★ 这个程序永远不需要管理员权限。不要用「以管理员身份运行」。

  「切换模式的那个键按了没反应」

     多半是被别的常驻软件占用了。打开设置，在「模式切换按键」那里换一个，
     旁边会当场告诉你这台电脑上能不能用。或者干脆改用扫码切换（见第三节）。

  「换成 2.4G 无线之后就不工作了」

     无线接收器插上之后，Windows 未必把它当成串口设备。双击运行
     工具\检查扫码枪.bat，它会在同一个文件夹里生成一份
     扫码枪检查结果.txt，把那份文件发回来即可判断。

     建议做两次：先拔掉接收器跑一次，再插上跑一次，对比多出来的是什么。
     （第二次跑之前先把上一份结果改个名字，否则会被覆盖。）

     这个脚本是只读的，不改任何设置、不装任何东西、不需要管理员权限。

  报问题的时候，请把 %APPDATA%\ScannerHelper\logs\ 里当天那个 .log 文件
  一起发过来。里面记着每一枪的结局、每一次连接与断开、每一次模式切换。
